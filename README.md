<h1>Projeto Amigo Secreto</h1>

<h2>Sobre</h2>
<p>Desafio proposto pela Alura</p>
<p>Uma página HTML que recebe do usuário nomes de amigos e faz o sorteio para saber quem é o amigo secreto da vez.<p>
<p>Após um nome ser sorteado é possível reiniciar o processo e sortear novamente.<p>
<p>Os botões foram e a caixa de texto foram estilizados com CSS e se tornaram funcionais com o JavaScript.<p>
